# 发布与隐私检查清单

本清单用于真机测试和发布准备，不表示当前已完成。

## 产品与内容

- [ ] 首页与结果页始终显示估算声明
- [ ] 不出现诊断、治疗、减重承诺、疾病预防承诺
- [ ] 不推荐极端饮食、断食、代餐、药物或保健品
- [ ] 运动建议不使用“抵消食物”的惩罚性表达
- [ ] 油盐提示明确“照片无法测量”
- [ ] 急症、疾病、用药、孕期、儿童问题有转介专业人员的文案
- [ ] 演示数据有醒目标记，未被宣传为真实 AI 结果
- [ ] AI 生成/合成语音有适当标识（按平台与法规要求）

## 隐私

- [ ] 微信隐私保护指引已声明相机、相册、云存储、设备信息使用
- [ ] 声明 DeepSeek 处理图片/文本、腾讯云处理朗读文本
- [ ] 用户协议与隐私政策可访问
- [ ] 用户可删除全部数据，删除路径经过验证
- [ ] 如果照片清理失败，UI 明确显示“未完全清理”，而非成功
- [ ] 已披露清空后保留不含 openid 的当日用量计数
- [ ] 原图分析后删除，餐次记录不含图片
- [ ] 未完成分析的上传有过期清理机制
- [ ] 数据访问仅限本人，跨账号测试通过
- [ ] 日志不含照片、对话原文、密钥或过敏原文
- [ ] 数据分析/存储区域符合适用的数据合规要求
- [ ] 第三方 SDK/服务清单已整理

## 权限

- [ ] `scope.camera` 用途说明与隐私指引一致
- [ ] 相册访问失败有可恢复路径
- [ ] 相机权限拒绝后可通过设置恢复
- [ ] 不请求与营养分析无关的敏感权限

## 安全

- [ ] DeepSeek/TTS 密钥仅在服务端环境变量
- [ ] 小程序包扫描无密钥或内部端点
- [ ] 云数据库客户端读写关闭
- [ ] 云存储最小权限已验证
- [ ] 上传图片魔数/尺寸/大小校验有效
- [ ] 跨用户读取/修改/删除被拒绝
- [ ] 每日配额与限流已启用
- [ ] 错误响应不包含内部堆栈/供应商原文
- [ ] 维护接口 secret 未进入客户端
- [ ] 依赖漏洞扫描完成

## 性能与稳定性

- [ ] Wi-Fi / 4G / 弱网测试完成
- [ ] P50 照片到文字结果记录，目标约 5 秒

- [ ] 页面在请求中保持可响应
- [ ] 语音生成不阻塞文字
- [ ] 首页、今天、设置页在空数据下可用
- [ ] 大字体、深色系统设置、常见屏幕尺寸检查
