# 食物成分数据说明

## 范围

`cloudfunctions/api/src/data/food-database.json` 是一个小型精选数据集，当前约 58 个条目，覆盖：

- 米饭、面食、粥、饺子、包子、油条等主食/早餐；
- 青椒肉丝、番茄炒蛋、麻婆豆腐、红烧肉、清蒸鱼等常见家常菜；
- 植物油/盐风险较高或较低的典型菜品对比；
- 常见水果、奶类、坚果、饮品和糕点；
- 13 个类别回退范围。

每条数据是**每 100g 可食部**的估算区间，而不是某一盘菜的精确实测值。

## 来源

1. 中国营养学会《中国居民膳食指南（2022）》
   - 用于膳食结构、食物多样性、少油少盐等一般原则。
   - <https://www.cnsoc.org/>
2. 中国疾病预防控制中心营养与健康所《中国食物成分表（标准版·第6版）》
   - 用于常见食物营养量级参考。
   - <https://www.chinanutri.cn/>
3. USDA FoodData Central
   - 公开数据，用于部分食物营养量级交叉核对。
   - <https://fdc.nal.usda.gov/>

## 编辑原则

- 用区间表达不确定性，避免伪精确。
- 针对中餐熟制状态给出常见范围（例如“青椒肉丝”，而不是生猪肉）。
- 保留别名，提高自然语言匹配率。
- 为油/盐风险只设置定性等级，不设置克数。
- 未命中时使用同类别更宽范围，并明确告知用户。
- 不复制任何商业食物数据库的完整结构或内容。

## 局限

- 中餐烹饪用油、用盐和份量差异很大。
- “家常菜”的做法在不同地区差异显著。
- 照片无法精确估计食物重量、可食部比例或隐藏配料。
- 不能用于疾病管理、医疗营养治疗或营养处方。
- 本数据没有经过临床验证或官方食品成分数据库认证。

## 更新流程

1. 记录新增条目的来源。
2. 用 `[min,max]` 表示每 100g 区间。
3. 添加常用别名。
4. 运行 `npm test`；数据完整性测试会检查 ID、区间和回退。
5. 在 `ARCHITECTURE.md` 与 `README.md` 中同步当前版本/范围（如发生明显变化）。
